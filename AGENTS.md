# Project instructions

## Git workflow

- Never push directly to main, including force pushes.
- Create a separate branch before committing changes.
- Commit and push changes to that branch, then review the diff and run appropriate checks.
- Merge through a pull request only after review finds no unresolved issues and required checks pass.

## Computer and browser access

- Never use full desktop or native computer control, or personal browser windows or tabs.
- Use only an agent-owned isolated or sandbox browser when browser access is needed.
- Prefer connectors, APIs, command-line tools, and local repository contents.
